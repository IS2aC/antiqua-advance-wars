# Commande : tuiles / breche

- Références à joindre : `art/raw/sprites-terrains/tuiles-debase.png` (image 1, format et style)
- Livrable : `art/codex/livraisons/sprites/breche.png`

## Prompt

```text
STYLE: true pixel art for a top-down tactical turn-based strategy game in the spirit of early-2000s handheld consoles, drawn on a strict pixel grid and scaled up 8x with nearest-neighbor so every game pixel is a perfect square block. No anti-aliasing, no blur, no gradients. 1-pixel dark brown outline (#2B1B17), light from the top-left, limited palette. Match exactly the style, the pixel size, the outline and the colors of the attached reference image.

The attached image is the base terrain tile sheet of this game: square tiles in rows, 4 variants per row, separated by thin gaps of flat magenta #FF00FF.

Draw ONE new row in exactly the same format: 4 square tiles side by side, separated by thin gaps of flat magenta #FF00FF, same tile size as the reference. Each tile is a breach in a fortress wall seen from above: a pile of fallen ochre mud-bricks and sandstone rubble on dusty ground, passable, the same bricks as an intact wall, each variant with a different pile. No people, no text.
```
