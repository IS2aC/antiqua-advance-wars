## Prompt

```text
STYLE: true pixel art for a top-down tactical turn-based strategy game in the spirit of early-2000s handheld consoles, drawn on a strict pixel grid and scaled up 8x with nearest-neighbor so every game pixel is a perfect square block. No anti-aliasing, no blur, no gradients. 1-pixel dark brown outline (#2B1B17), light from the top-left, limited palette. Match exactly the style, the pixel size, the outline and the colors of the attached reference image.

The attached image is the buildings sheet of this game: each building twice, first neutral (grey flag and grey trim) then team-red (red flag and red trim), side by side on flat magenta #FF00FF, all with the same width and the same ground line.

Draw ONE new building in exactly the same format: a small African harbour (port) on the shore, twice, side by side on flat magenta #FF00FF: first the neutral version (grey flag, grey trim), then the team-red version (red flag, red trim, using ONLY the reds #4A1218, #8E1F24, #D13A2E, #F2735A for the team parts). The harbour: a mud-brick warehouse with a flat roof and a small tower with a flag, a short wooden jetty with mooring posts in front, coiled ropes and two jars, a strip of blue water along the bottom edge of the building. Same size as the barracks of the reference (one tile wide, taller than wide), feet on the same ground line. No text, no other buildings, no ground outside the building.
```
